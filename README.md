# 证件照排版 MAX

这是一个 Photoshop UXP 面板插件项目，用于开发证件照排版工具。

当前版本为 v0.6.2（自动取码接入与来源兼容整改开发中）：取件码模式可以持续开启，普通入口仅对原规则认定的本店新拍自动交付；外来、历史重印、无日期／来源不明照片仍按原选项排版，整条信息条留白，不依赖后台。旧片补交需明确确认本次照片。交付必须取得本次有效六位码才能输出，失败保留原任务，连接与恢复面板提供受控重试和停止等待；不会超时后自动打印或新建交付。关闭模式保留原信息条与普通输出资格，多规格草稿仍须后台核对完成。详见 `docs/pickup-code-mode.md`；开发检查、独立审查、实际安装与用户验收分别记录，未正式发布。

## 如何加载

1. 打开 Adobe UXP Developer Tool。
2. 点击 `Add Plugin`。
3. 选择包含 `manifest.json` 的项目根目录。
4. 点击 `Load`。
5. 修改代码后点击 `Reload`。

## 更新已安装插件

1. 双击 `IDPhoto-MAX-Setup-v0.5.8.exe`。
2. 按提示同意 Windows 管理员授权。
3. 更新器先读取 Adobe 对本插件的唯一登记路径，再确认本机存在精确的 `DS-RX1` 和普通 `(6x4)` 纸张，部署 Windows 打印桥并原位更新插件。目录名里的旧版本号不作为移动或删除依据。
4. 完全退出并重新打开 Photoshop，再从“增效工具”菜单打开插件。

此 EXE 用于更新已有 Adobe 登记的插件。首次安装需先通过 Adobe 的 CCX 安装流程完成登记，或使用上面的 Developer Tool 开发加载方式；仅复制目录不能替代登记。缺少登记、打印机、纸张或兼容 Photoshop 时，更新器会明确停止。

## 项目结构

- `src/`：插件运行时代码；`core` 负责业务流程，`photoshop` 负责 Photoshop 操作，`ui` 负责面板。
- `tests/`：自动化回归测试。
- `bridge/`：DS-RX1 Windows 打印桥。
- `scripts/`：验证、打包、安装和 EXE 构建脚本。
- `docs/`：项目文档和架构决策；详细目录约定见 `docs/README.md`。
- `_reference/`：本地参考图目录，保留为空也不能删除。
- `dist/`、`backups/`：本机生成物和备份，保留在工作区但不提交 Git。

## 当前执行链路

点击“开始排版”后：

1. 读取当前 Photoshop 活动文档。
2. 根据当前模板做宽高比例检测；结婚证竖向源图先自动旋转为横向。
3. 比例 1% 内跳过裁切；比例不符时，非正方形模板使用快速构图：横向原图居中裁左右，纵向原图保留顶部并主要裁下方。1:1 正方形模板自动扩展画布并执行内容识别填充。整个流程不调用 Photoshop“选择主体”。
4. 将处理后单张调整为模板物理尺寸对应的 600ppi 像素尺寸。
5. 创建 3600x2400px / 600ppi 的 6 寸拼版画布。
6. 按当前模板的 JPG 参考图 `photoSlots` 复制照片到拼版画布。
7. 根据 JPG 参考图定义的 `infoBar` 绘制右侧或底部信息条，或跳过信息条。
8. 如果开启 DS-RX1 快速打印，则导出临时拼版 JPG，通过 Windows 打印桥固定发送到 `DS-RX1` 的普通 `(6x4)` 纸张一份。
9. 如果开启导出单张 JPG，所有尺寸共用裁切前的原片身份与底色。同一原片、同底色、近似宽高比（相对差不超过 2%）只保留像素面积最大的 JPG，正方形等明显不同比例分别保存。本店相机须同时具备当天有效的 `exif:DateTimeOriginal`；旧相片、缺失日期、无法确认身份或底色时跳过存档并说明原因。
10. 如果开启 NAS 日期归档，则通过 UXP 文件夹授权保存到日期目录。
11. 自动关闭处理后单张临时文档，不保留在 Photoshop 标签栏。

日期目录中的 `.idphoto-jpg-index.json` 是配套身份记录，随照片一起保留和迁移，用于重启或换电脑后的可靠去重。旧版没有完整身份记录的文件不会仅凭短编号自动删除。新 JPG 与身份记录都保存成功后才清理同组较小照片；目录权限导致清理失败时会明确提示。

## 尺寸选择与执行

- 单击尺寸按钮可切换选中或取消，按钮高亮表示已选；无需按 Ctrl。
- 可连续点选多个尺寸，点击“排版”后按点选顺序依次生成多个排版文档。
- Shift + 单击仍可用于连续范围选择。
- 双击尺寸按钮会保留当前多选，并立即执行；双击的尺寸尚未选中时会先加入选择。

## 裁剪与扩图策略

设置页提供三种策略：

- 默认裁切：横向原图居中裁左右，纵向原图从顶部开始保留目标比例，多余背景直接裁掉，不自动补边。
- 内容识别填充扩图：先扩展画布到目标比例，再尝试 Photoshop 内置内容识别填充补边，失败后 fallback 到默认裁切。
- 自动模式（默认）：非正方形模板使用无进度条快速裁切；目标比例为 1:1 时自动执行内容识别填充扩图，适用于阿根廷4x4、美签5.0x5.0和美签5.1x5.1。补边选区会按原图尺寸向内重叠一小段，避免原图边缘形成笔直拼接线。仍可手动选择“内容识别填充扩图”强制其他比例补边。旧版本保存的默认裁切会一次性迁移到自动模式。

裁剪策略由 `src/core/cropStrategyStore.js` 写入版本化设置档案。执行时优先读取当前设置页已选择的策略。

## 设置档案与备份

设置页可备份或恢复店铺文字、裁切策略、本店相机名单、调试模式与模板覆盖、NAS 目录显示标签。NAS 的 UXP 持久授权令牌不会写入 JSON，换电脑恢复后仍需重新选择 NAS 文件夹。DS-RX1 打印桥由一键安装程序独立部署，不属于设置档案。恢复设置时会同步刷新表单、相机状态、NAS 状态和调试面板，并清空旧的内存调试覆盖，避免恢复值被遮住。

## 全模板视觉验收

调试页的“生成全部模板供验收”会用当前原片依次生成全部 11 个拼版文档。该入口强制关闭 DEBUG 图层命名，并通过排版任务禁止 JPG、NAS 和快速打印；最终文档保留在 Photoshop 中供肉眼比对，处理后单张临时文档仍自动关闭。

## DS-RX1 快速打印

- “快速打印 · DS-RX1”开关位于排版页输出选项，插件每次 Reload 后默认关闭，避免误打。
- 开启后，每个成功生成的 6 寸拼版文档发送一份到 DS-RX1；多选几个尺寸就分别打印几张。
- 首次安装时由 `install-plugin.cmd` 部署本地打印桥并注册 `.idprint` 文件关联；插件设置页不再提供校准按钮。
- 打印桥精确匹配 `DS-RX1` 和普通 `(6x4)`，不会选中 `(6x4) x 2`、系统默认打印机或 Photoshop 最后一次打印机。
- 拼版文档先另存为临时 3600x2400 JPG 副本，原拼版不保存、不关闭、不改变格式。
- Windows 桥接返回打印机、纸张、份数全部确认成功后，插件才显示“已打印”；启动失败、超时、结果异常或驱动缺项全部 fail closed。
- 第一次打开 `.idprint` 时 Photoshop 会显示权限请求；可勾选“记住我的选择”后允许，后续不再重复询问。
- 打印失败不关闭最终拼版、不回滚 JPG/NAS，也不会自动重试浪费相纸。

## 信息条

信息条位置和大小由 `template.infoBar` 驱动，来源为 `D:\codex\_reference\` 中对应 JPG 模板。renderer 不再自行猜坐标。

当前信息条会绘制：

- 深红背景色块
- 来源照片缩略图
- 店铺名称
- 自动当天日期
- 电话
- 提示语

如果 `infoBar.enabled=false` 或 `position=none`，不会绘制信息条。

## 快捷键

快捷键只在插件面板获得焦点时工作。输入框中打字时不会触发快捷键。

当前没有假装支持真正 Photoshop 全局快捷键。UXP 面板内 `keydown` 只能在面板获得焦点时稳定工作；后续如需进入 Photoshop 快捷键系统，需要继续验证 UXP command / menu command 暴露命令与 Photoshop 宿主快捷键绑定的兼容性。

## 测试建议

1. Reload 插件后先打开一张普通照片。
2. 逐个选择 11 个尺寸模板并执行。
3. 查看状态栏是否显示具体步骤和错误位置。
4. 检查新建 6 寸画布尺寸、照片排版数量、信息条位置。
5. 测试 J/N 开关对导出和 NAS 的影响。
6. 在设置页选择、更换或清除 NAS 目录授权；未提前授权时，第一次 NAS 归档会触发文件夹选择。

## 验证与发布

- `npm test`：运行 Node 自动测试。
- `npm run verify`：运行测试、全量 JavaScript 语法检查、版本/build 一致性、Photoshop 执行 seam 与已下线功能检查。
- `npm run package:exe`：验证通过后生成 `dist/IDPhoto-MAX-Setup-v0.5.8.exe` 和对应 SHA256 文件。
- `scripts/install-plugin.ps1 -DryRun`：只验证安装包和目标 Photoshop，不写入系统。
