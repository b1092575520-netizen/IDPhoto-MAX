# 门店流程优化 v0.6.4（SWO-R1）

本轮为待独立审查的开发候选，日常安装仍为已交付的 v0.6.2。

SWO-R1 修复普通旧归档被新交付接管：普通去重相似、原片标记、同名或相同字节均不证明交付归属。新任务只复用已明确属于同一任务的受管文件；没有归属的旧JPG保留不动，可靠保存本次输出后再建立映射。同任务最大档保留它原有文件序号，不改绑为这次较小规格。

每次复用核对不可变请求摘要、映射中的精确文件序号和上传摘要、目录与索引归属及本地照片摘要，打印片与上传片允许不同字节。写入前保留明确产出计划；完成后分别保存独立完成回执和本地映射。单处映射、交接或索引故障解除后，主动重试恢复准确记录，不重复保存、不重建或重传云交付。两处完成记录都未落盘、清单/照片/索引冲突时，保留原计划与照片并提示人工核对，不凭文件名补绑定；不要删除标记强行重试。

同一顾客做完交付后仍是“当前顾客”。取消打印、补印或重新打开插件不会自动建单。先打开“核对当前顾客”，对照持久化原成片，勾选确认后主动重拼/补印；换人使用“开始下一位”。原任务目录、清单和完成标记不会删除。更换照片内容要使用原有修订/多规格流程，不能用旧原片重拼代替上传新内容。

每次输出重新向原后台及原云连接核实任务、交付和有效码；渲染完成和实际打印前再次核对。取消、撤回、换码及在途管理冲突按服务端处理，失败停止相关输出。网络恢复不自动打印。

普通模式保留原版横竖信息条、来源分流与归档资格。美签5×5保留五张，普通模式空位留白；明确交付才有取码条。第五版取码条长边≤60mm，四边至少24px（600ppi约1mm），窄条左对齐，竖条照片与文字整体转向。普通版仅对贴边内容作最小修正。

设置页可以选择本店真实小程序码，先用微信核实，再勾选确认并选择完整正方形PNG/JPG。插件保存独立副本和摘要；缺少资产时正常输出不含扫码的说明，不印占位图。图上的18mm空间不能代替纸面扫码验证。

普通JPG归档继续按原片、底色、比例保留最大档。有交付的文件同时写不可变映射，后台每约30秒查询精确文件发布证明，满足后用当前有效码作前缀。稳定归档编号防止多人同码同规格覆盖。打印归档与云端高清片可不同尺寸和摘要。Photoshop关闭后已登记映射仍能同步。多规格每份归档绑定本批文件序号；后台人工完成前不能借旧交付ready改名。归档失败可从当前顾客面板重试本批本地归档，不重复生成云任务。

故障时保留照片、原名或已发生的改名事务。后台详情显示“本地归档命名待同步”；恢复网络/目录权限或解除文件占用后原动作重试。双索引事务未完成时插件暂停该目录新归档，避免同时写入。后台原生锁随进程退出释放；插件崩溃遗留锁只在Photoshop完全退出后由后台恢复，不按超时抢占。

升级必须包含云函数photoService的archiveNamingStatus、配套后台与插件。先保留完整队列备份、原插件和归档根目录；不要删除 `.idphoto-*` 文件和插件数据。新后台可读取旧任务，但不会猜测历史照片取件码。隔离恢复副本不会改动日常归档。回退按主项目安装与恢复说明执行，不能只覆盖插件后丢弃新后台事务记录。
