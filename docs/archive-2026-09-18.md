# v0.5.8 通用尺寸去重与日期排序

## 根因和规则

2026-09-18 的 3 张示例文件已核对。原索引仅含 09:18 的一寸；Photoshop 日志 09:21:37 / 09:21:49 显示桥没有确认后两次索引。保留的作业没有对应提交标记/回执；不能把所有此类情况推断为已打印成功。此前因索引失败而保留照片的保护导致重复，但不会丢失 JPG。

原 2% 比例阈值不能覆盖小二寸与标准二寸约 4% 的差异。现在使用所有尺寸通用规则：相同原片的强身份/高置信视觉身份、相同底色，两个宽高比的大者除以小者不超过 1.05，保留像素面积最大者。横竖、方形与明显不同的比例继续分别保留。跳过导出时，清理候选还必须接近最终保留照片，避免非传递相似关系误删。既有相机资格和历史照片排除不变。

## 持久记录

插件私有数据目录 `archive-index-cache` 按完整存档路径保存身份记录，校验路径以防文件名哈希冲突；每次完整暂存、原子替换成功后才允许清理较小照片。内部记录损坏/写入失败时仍保留新旧 JPG 并提示。

照片目录的 Hidden 索引继续以原桥同步；共享同步失败显示单独提示，并保留私有完整记录，因此下一次操作/重启仍能去重。跨电脑使用 NAS 时仍依赖共享索引成功同步；只在本机保存的失败同步记录不会自动出现在另一台电脑。没有增加 shell 启动或重试权限弹窗。

## 日期视图

Windows 桥仅对 `yyyy/yyyy-MM/yyyy-MM-dd` 日期层级配置视图。通过 `SHGetViewStatePropertyBag` 分配并标记精确目录的视图键，然后写入在本机原生视图中取得的日期倒序 Sort 数据和必要的初始视图字段。不存在修改 AllFolders 的路径。首次配置后记录路径和版本，不反复覆盖用户主动调整的排序。

单独用 Sort 值不足以初始化从未打开的视图，需 Rev/Mode 等字段。新目录首次打开已通过 Shell `Document.SortColumns` 实测为 `prop:-System.ItemDate;`，对应资源管理器“日期”倒序。参考 [微软视图属性包 API](https://learn.microsoft.com/en-us/windows/win32/api/shlwapi/nf-shlwapi-shgetviewstatepropertybag) 和 [文件夹视图排序 API](https://learn.microsoft.com/en-us/windows/win32/api/shldisp/nn-shldisp-ishellfolderviewdual3)。排序失败独立返回告警，不撤销索引或照片。
