# v0.6.8 插件交付自动化与新原片身份

2026-10-15增量：没有ImageUniqueID或OriginalDocumentID的新原片，可用机身序列号＋完整DateTimeOriginal＋原始亚秒建立 `source-v2` 身份，时区偏移可读时保留。身份强度另行区分（相机编号/原片文档编号/拍摄亚秒），强编号格式或同文档字段冲突仍拒绝。无亚秒且无强编号仍无身份。原有有强编号、无亚秒的合法 `source-v1` 继续兼容。

EXIF `53`表示原始亚秒数字；Photoshop可能写成内嵌`.053`。有单独EXIF亚秒时，以原数字串为准，只接受标准小数尾零等价或已核实的1/2位亚秒左补到3位映射，其余冲突返回空身份。零亚秒是有效值，不等同于缺失。单独偏移从OffsetTimeOriginal读取；不使用保存/修改/数字化时间。

同一原片首次保存补出OriginalDocumentID不会改变source-v2键，文件名、像素和普通DocumentID仍无关。原索引中精确匹配同机身/完整原拍摄时间/亚秒的source-v1任务会继续沿用旧键和原任务，不改写原记录；已有强编号与当前同类型编号冲突时不匹配，多个旧键同时匹配则停止交付人工核对。接受同机身极端同刻亚秒碰撞为同原片的风险，是本轮用户明确决定，不扩大为顾客权限。

取件码模式无法读身份时，最终状态栏显示“这张照片读不到拍摄编号，本次只排版、不出取件码”；外来、旧片、日期不明保留来源检查原message。没有新增按钮或弹窗。0.6.8覆盖日常前需完成本轮实测/发布校验、本地Git提交及上一版回退，覆盖前告知用户；实际安装状态以本轮回执为准。
