# v0.6.7 插件交付自动化

主契约在 `D:\software\yx Applets\docs\plugin-ui\服务契约-插件交付自动化-2026-10-07.md`，验证和候选在主项目 `review/plugin-automation-20261007/`。本轮源码为开发候选，未覆盖日常 External 0.6.6。

取件码开启时，可靠本店新原片自动取新码；同原片、同规格底色替换当前照片，不同规格底色追加，均沿用当前有效码。外来、旧片、日期或原片身份不明保持只排版、信息条留白。旧片补交走“电子交付 / 旧片补交”并明确确认。未知底色需核对，不自动覆盖其他照片。

连接恢复自动补完原任务与原字节，不自动打印。恢复提示中的打印按钮才会启动原 DS-RX1 流程；已经有输出或未知打印痕迹的任务需人工核对。停止等待的任务保留，不被自动恢复绕过。

同行开启期间共用最早顾客的码；可勾选最近30分钟已完成交付，已有有效旧码继续领取。20分钟无新排版自动关闭，关闭后下一张新原片独立取码。误并入在电脑交付管理停止共享/拆分，已下载文件无法远程收回。

必须配套支持 `pickup-automation-1` 的后台；清单v3的单张自动交付仍需可靠完成信号才发布。旧v2多规格草稿人工确认不变，插件已撤掉规格面板，特殊照片在电脑后台添加。新持久索引损坏/归属冲突保留记录并停止，不删除标记绕过保护。
